# 手工验收清单

> 真实样片由用户在本机通过 `npm run dev`（或打包后的 exe）验收，样片不提交仓库。
> 对应 `PLAN.md` §8.3。

## 1. 导入与信息

- [ ] 拖入 1 个视频文件：5 秒内显示容器、时长、大小、编码、分辨率、帧率、码率、像素格式、音频编码/码率/声道/采样率。
- [ ] 拖入多个文件：全部进入队列，逐条显示状态。
- [ ] 拖入文件夹：递归扫描出其中的视频文件。
- [ ] 拖入无音轨视频：界面提示「无音轨」，转换正常。
- [ ] 导入非视频文件（例如 txt 改后缀）：给出「无法识别媒体信息」，不加入执行。

## 2. 简易模式

- [ ] 拖动质量滑块：预计体积、分辨率、帧率、码率、命令摘要随动；刻度标签（极致压缩 → 近原画质）可点击。
- [ ] 键盘 ← / → 微调 1，Shift + ← / → 微调 10。
- [ ] 勾选「指定目标大小」并输入数值：滑块变为求解状态，显示等效质量档位与推导说明。
- [ ] 输入过小的目标体积（例如 0.5 MB）：明确提示不可达，并给出最小可达体积。
- [ ] 「将执行」区域可展开、可复制，内容与真正执行的参数一致。

## 3. 高级模式

- [ ] 切换「高级模式」：参数默认显示自动推导值，修改任一项后转为手动。
- [ ] 非法参数逐项报错：码率超限、CRF 越界、奇数尺寸、帧率高过 120。
- [ ] WebM 选 H.264 或 AAC：立即提示「WebM 仅支持 VP9/AV1 + Opus」。
- [ ] 输出扩展名与容器不符：提示或自动纠正。
- [ ] 额外参数填 `-i foo.mp4`：被拒绝并说明原因。
- [ ] 「重置为自动」恢复为估算推导值。

## 4. 转换过程

- [ ] 转换中显示百分比、速度、ETA，进度平滑推进。
- [ ] 转换中点击「取消」：状态变为「已取消」，输出目录无 `.part` 残留。
- [ ] 队列 ≥5 个文件时顺序执行；「全部取消」对所有任务生效。
- [ ] 转储目录只读 / 磁盘不足时给出明确中文错误与建议。

## 5. 结果

- [ ] 完成卡片显示输出路径、实际体积、实际编码器 / 分辨率 / 帧率 / 码率、压缩率、耗时。
- [ ] 「打开所在文件夹」正确定位到输出文件。
- [ ] 失败时显示错误分类、最后 20 行 ffmpeg 输出与修复建议。

## 6. 日志与设置

- [ ] 日志抽屉可展开、搜索、按级别过滤、自动滚动、导出到文件。
- [ ] 设置里修改默认质量 / 命名模板 / 并发数后重启应用仍生效（保存在 `%APPDATA%\shrinkly\settings.json`）。
- [ ] 命名模板填入未知占位符（如 `{bogus}`）：给出错误提示。

## 7. ffmpeg 缺失模拟

- [ ] 临时把 ffmpeg 从 PATH 隐藏（或在设置里指向不存在的路径）：顶部状态条变红，任务按钮禁用并说明原因。
- [ ] 点击「用 winget 安装」：可见流式安装日志；安装成功后自动重新检测。
- [ ] 安装失败（例如断网）：展示手动指引，可继续用「选择路径」指定 ffmpeg.exe。

## 8. 打包产物

- [ ] `npm run build:win` 产出便携 exe 与 NSIS 安装包。
- [ ] 在干净目录双击便携 exe 可启动并完成一次完整转换。
- [ ] 安装包安装后从开始菜单启动正常。
